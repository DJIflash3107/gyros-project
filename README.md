# Gyros Project

An end-to-end intelligent operational management platform for multi-branch food & beverage businesses.

## Modules

- [**Backend API**](./backend/README.md): FastAPI, SQLAlchemy 2.0, AMD Token Factory integration, LangGraph Business Operations Agent, Sales Report Ingestion & LLM Semantic Mapping, Predictive Demand Forecasting, and the Business Action Center.
- [**Frontend Web Application**](./frontend/README.md): Modern Next.js / React application with interactive dashboards, reports review, operational agent chat, forecasting visualization, and action center.
